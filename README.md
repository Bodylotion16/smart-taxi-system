# Smart Taxi System

## Beschrijving
Een realtime taxibeheerplatform voor admins, chauffeurs en klanten.

## Technologieën
* Frontend: HTML5, CSS3, JavaScript (Vanilla)
* Backend: Node.js, Express
* Database: MySQL
* Authenticatie: JSON Web Tokens (JWT)

## Vereisten
* Node.js v18+
* MySQL Server

## Installatie
1. Kloon de repository
2. Run `npm install`
3. Richt de database in met het SQL-bestand
4. Start de server met `node server.js`

## Database Setup
Importeer het bestand in de `sql/` map in MySQL Workbench.

## Gebruik
Open de applicatie via localhost:3000 om in te loggen.
